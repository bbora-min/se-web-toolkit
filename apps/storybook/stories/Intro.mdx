# SE Web Toolkit

내부 엔지니어링 도구를 위한 디자인 시스템. 이 Storybook 은 **사람용** 창이다 — Claude 가 읽는 스킬 레퍼런스(`plugin/skills/se-ui/references`)와 같은 TSDoc 에서 문서가 생성되므로 둘이 어긋나지 않는다.

## 보는 법
- 상단 툴바 **아이덴티티**를 바꾸면 같은 컴포넌트가 서비스마다 어떻게 보이는지 바뀐다 — 액센트·뉴트럴·밀도가 `se.identity.json` 슬롯이다.
- **테마**(라이트/다크)와 **밀도**(compact/comfortable)도 툴바에서.
- 각 스토리의 **문서** 탭에 prop 표와 설명이 있다. 설명은 소스의 TSDoc 그대로.

## 순서
1. **아이덴티티 › 가족 초상화** — 등록된 서비스 전부를 나란히. "같은 팀이 만든 것 같은가, 그런데 다른 제품인가" 를 여기서 본다.
2. **시그니처** — 서비스의 얼굴 다섯 종. 서비스의 핵심 질문에 맞춰 하나를 고른다.
3. **패턴 · 컴포넌트 · 차트** — 화면을 조립하는 재료.

## 코드에서 쓰기
```tsx
import { Button, DataTable, StatusStrip } from '@se/ui'
import { BarChart, ChartCard } from '@se/charts'
```
색은 토큰 클래스만(`bg-accent` `text-muted` …), 컨트롤은 `@se/ui` 만, 화면마다 로딩·빈·에러 3상태. 이 셋은 `@se/eslint-plugin` 이 강제한다.
새 서비스는 `/se:new`, 기존 서비스는 `/se:adopt`, 업데이트는 `/se:upgrade` — 저장소 README 참조.
