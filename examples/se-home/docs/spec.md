# SE Home — 화면 명세

## 서비스
- 하는 일: SE 내부 도구 전부의 입구. 형제 서비스의 상태·마지막 배포·최근 본 것·온콜을 한 화면에.
- 주 사용자와 사용 순간: 모든 엔지니어, 아침에 처음 여는 탭. "지금 어디가 아픈가, 내가 하던 게 어디 있나".
- 분위기 3단어: 가볍다 · 친절하다 · 넓다
- 가장 중요한 화면: 홈

## 화면: 홈 — 허브(Hub)
- 라우트: `/`
- 답하는 질문: 내 팀의 서비스들이 지금 괜찮은가, 내가 하던 일은 어디 있나
- 데이터: `GET /api/home` → me · services[] (health ok|degraded|down, hue, shell, signature, lastDeploy) · recent[] · events[] (24시간) · oncall · notices[] · quick
- 1차 분류 / 2차 필터: 없음 — 허브는 고르는 화면. 검색은 ⌘K 팔레트
- 구조: 인사 + 상태 한 줄 → 큰 검색 + 빠른 진입 칩 → 시그니처(TimelineRibbon, 줄 = 서비스) → 서비스 카드 3열 (+ 새 서비스) → [최근 본 것 | 오늘: 온콜·공지]
- 주 액션: 없음(검색이 주 동선). 카드·행은 통째로 그 서비스 링크
- 3상태: 카드 스켈레톤 6장 / "아직 등록된 서비스가 없어요 — /se:new" / "레지스트리에 연결할 수 없어요 · 다시 시도"
- 시그니처에 넣을 숫자: 배포 N · 장애 N

## 화면: 서비스 — 원장
- 라우트: `/services`
- 답하는 질문: 형제들의 아이덴티티(hue·쉘·시그니처)와 상태를 비교하면
- 표 컬럼: 서비스(마크+이름) · 상태 · 지금 · hue · 쉘 · 시그니처 · 담당 · 마지막 배포 · 열기
