# SchedulePage — 일정 · 시간이 x축

원본: `references/examples/release-desk/CalendarPage.tsx`(배포 캘린더 — 월 격자 · 프리즈 빗금 · 고른 날의 창 목록)

"언제"가 질문인 화면이다. 배포 창·온콜 교대·배치 스케줄·프리즈(Google Calendar·Cal.com·PagerDuty). 같은 항목을 표(원장)·보드(흐름)로도 보지만 몰림·겹침·금지 구간은 격자에서만 보인다. 프리즈 배너가 여기선 빗금 구간이 된다 — 배너는 없어도 된다.

## 골격
```
<PageBody>
  <PageHeader title actions={[◀] 2026년 9월 [▶] [오늘]} />          ← 월은 URL(?month=YYYY-MM), 고른 날은 ?day=
  <grid [minmax(0,1fr)_300px]>
    <CalendarGrid month events spans selected today onSelectDay onSelectEvent />   ← 일요일 시작 7열, 칸 96px, 칩 3 + "+n"
    <범례 한 줄>                                                       ← 칩 색 = 단계의 의미 색, 구간 = 빗금
    <aside>  고른 날 제목 · n건 → (프리즈면 한 줄) → 창 카드 목록(식별자 · 유형 · 제목 · 서비스 · 단계 · 위험 · 담당 · 시각)
  </grid>
</PageBody>
```

## 결정 규칙
- **색은 새로 만들지 않는다.** 칩은 항목의 상태(단계)가 가진 의미 색(`StageBadge` 와 같은 값), 구간은 warning 빗금(`.se-cal-span-warning`). "캘린더별 색"은 내부 도구엔 없다
- **오늘은 액센트 점, 고른 날은 액센트 테두리.** 둘이 겹치면 둘 다
- **여러 날에 걸친 항목은 매일 칩이 놓이고 첫날만 진하다.** 가로로 이어 그리는 바는 6주 격자에서 깨진다 — 하지 않는다
- **날을 누르면 오른쪽, 칩을 누르면 상세.** 격자 안에서 편집하지 않는다(드래그로 창 옮기기 등은 상세의 폼)
- **주말·공휴일은 글자색으로만**(일 danger · 토 info 옅게). 칸 배경을 칠하면 빗금(구간)과 헷갈린다
- **범례는 격자 아래 한 줄.** 색이 넷 이상이면 이미 잘못됐다
- 데이터는 월 단위로 받는다(`GET /api/calendar?month=`): 창 + 구간. 격자가 이웃 달 며칠을 보여 주므로 백엔드는 앞뒤 일주일을 더 준다
- 1024px: 오른쪽 목록이 격자 아래로. 격자는 7열을 유지한다(칩은 말줄임)

## 3상태 (톤은 se.identity.json)
- loading: 격자 자리 스켈레톤 560px + 오른쪽 카드 스켈레톤 3
- empty: 격자는 남는다(달력은 비어도 달력이다). 오른쪽에 "배포 창이 없습니다" + 다음 행동
- error: 격자 대신 원인 + 다시 시도
